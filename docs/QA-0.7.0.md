# 0.7.0 通用适配回归记录

日期：2026-08-25。

## 新基线

- 手机前端 `ui/index.html` SHA-256：`FC16E0376CDB7F61F80C48C207F57EE2AD98B07F70C31DD7339620C2EBCF14C9`。
- 模型插头只保留自定义直连，旧配置读取时会迁移为 `direct`。
- 世界类应用采用“当前世界书优先、所选地域模板兜底”的统一读取合同。

## 修改结果

- 信息应用为变量检查、清理补齐、桌宠切换、楼层模式、选楼和楼层刷新提供处理中、成功或失败反馈。
- 人物档案在 MVU 数据之外只读抽取世界书中明确标注性别的人物；手动性别修正按聊天范围保存。
- 新增头像库应用，支持批量上传 PNG、JPEG、WebP、GIF，限制单张 8MB、最大 4096×4096，并可应用到所选角色。
- 地图、监控、日历、成就和任务、打工、MC匿名版统一接入世界书/模板适配层；设置页可切换中国版或日本版。
- 邂逅不再加载内置偶遇和角色包，并一次性清理旧角色包与单独角色库；导入与编辑能力保留。

## 自动检查

- 桌面端与窄屏均验证根文档无滚动、五个移动热区、两个无标志等比例缩放角和外部挂件隐藏。
- 模拟世界书提供地点与男性角色；地图显示世界书来源，男性档案正确加载，并可手动改为女性档案。
- 模拟世界书没有监控条目时，切换日本版后监控应用显示日本通用模板。
- 批量上传 1×1 PNG，保存到头像库并应用到目标角色。
- 信息页刷新检查后出现明确成功反馈。
- 邂逅空库不包含原内置人物或角色包名称。
- 自定义直连完成 `/models` 加载、列表选择、保存和 `/chat/completions` 测试；页面及配置中不再有后端代理选择。
- 静态检查、11 项单元测试、浏览器回归和构建全部通过。
