# HypnoOS 3.0 v0.7.4 QA

## 本次变更

- “档案”和“根据世界书自动生成”共用新的下拉多选控件。
- 控件默认收起为一行；展开后显示可滚动的世界书列表。
- 每项使用独立复选框，未选为白色方框，选中为粉色勾选。
- 摘要在未选、单选和多选时分别显示“请选择世界书”、世界书名称和“已选择 N 本世界书”。
- 原多世界书档案导入、合并生成、设置页滚动位置恢复逻辑保持不变。

## 自动化结果

- `npm run build`：通过。
- 扩展清单验证：通过，无警告、无未知字段。
- Node 单元测试：11/11 通过。
- Playwright 静态预览：桌面端与窄屏均通过。
- 已验证两个选择器默认收起、点击展开、两本世界书同时选中、粉色选中反馈、已选数量摘要、多世界书档案导入与合并生成。
- 手机外层无页面滚动，四边拖动与左右下角同步缩放回归保持通过。
