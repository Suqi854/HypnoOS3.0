# HypnoOS 3.0 v0.7.8 QA

## 修正范围

- 成就、任务和每日生成只使用女性档案中已有角色，不再混入男性或未导入角色。
- 设置、信息、本轮输入、催眠APP固定在底部，顺序从左到右保持不变。
- 头像库等非固定应用统一参与拖动排序；隐藏应用后桌面自动连续补位。
- 日历底部新增课程表显示开关，关闭后隐藏课程表应用，重新开启后恢复。

## 自动验收

- 静态检查：UI 基线、女性档案限定、固定底栏、拖动排序、自动补位和课程表开关合同通过。
- 单元测试：11 项合同、导入、宿主适配和伴生世界书测试通过。
- Playwright + Chrome：桌面 `1180×900` 与窄屏 `760×900` 全部通过。
- 桌面实测头像库与帮助应用拖动换位成功，且没有误触打开应用。
- 固定底栏实测顺序为：设置、信息、本轮输入、催眠APP。
- 关闭课程表后返回桌面，课程表应用消失且剩余应用序号连续；重新开启后恢复。
- 任务原版 UI 中只出现模拟女性档案 `QA女性`，未出现 `QA男性` 或世界书原始杂项角色。
- 手机根文档无整页滚动，内部长列表滚动和整体同步缩放继续通过。
