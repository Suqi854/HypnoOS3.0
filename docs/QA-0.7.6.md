# HypnoOS 3.0 v0.7.6 QA

## 本次修复

- 催眠目标角色数据源改为“世界书导入档案 + 运行时档案缓存 + MVU角色变量”的并集；没有MVU变量的已导入人物仍可选择。
- 角色选择统一按已喜欢角色优先、其后女性、最后男性排序；各组内保持稳定中文名称排序。
- 密钥 `666666` 正确时直接开启作弊模式，不再被确认弹窗或固定4.3世界书条目缺失阻断。
- 《难度加大》《作弊模式》条目切换保留为兼容增强；缺失时显示提示并写入日志，但不会撤销已通过密钥开启的作弊状态。
- 开启后原底部蓝色按钮改为红色“作弊模式开启中”；点击该红色状态仍可关闭。

## 自动化结果

- Playwright 桌面端与窄屏均验证：导入的无变量女性、男性人物同时出现在催眠目标角色列表。
- 已喜欢男性人物排在第一；清除喜欢状态后，女性人物排在男性人物之前。
- 错误密钥保持未开启；正确密钥直接开启并持久化，红色状态条可见且文案正确。
- 手机外层滚动锁、四边拖动、左右下角缩放、原4.3应用路由及本轮输入回归继续通过。
- `npm run build`、扩展清单验证与单元测试结果以本版本最终构建输出为准。
