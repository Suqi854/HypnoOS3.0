# 0.7.3 多世界书与档案导入回归记录

## 本次变更

- 设置页重绘前记录内部滚动位置，点击选择、生成、导入或状态反馈后不再直接回顶。
- 通用适配模板支持多选世界书，将所选世界书只读合并后生成一份应用适配数据。
- “覆盖世界书”和“通用适配模板”之间新增“档案”面板，可多选世界书并导入明确标注性别的角色。
- 导入角色按性别进入女性档案或男性档案；未明确性别的条目不会猜测导入。
- 导入档案进入统一角色数据源，监控、任务、邂逅等读取人物资料的应用会同步读取。
- 男女档案顶部统一显示“档案”。
- 作弊模式增加独立密钥门控；当前密钥集中定义为 `666666`，仅控制是否允许开启作弊模式。

## 自动验收

- 静态检查与 11 项单元测试通过。
- Playwright 桌面端与窄屏通过：
  - 设置页切换为自动生成后保留原滚动位置；
  - 同时选择 `qa-book`、`qa-book-2`，生成结果保留两个来源名；
  - 两本世界书导入后女性 1 名、男性 1 名，女性档案可见对应角色；
  - 错误密钥阻止开启，正确密钥允许进入开启确认流程；
  - 手机外层滚动、移动和等比例缩放回归继续通过。
