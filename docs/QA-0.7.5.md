# HypnoOS 3.0 v0.7.5 QA

## 本次修复

- 修复“读取并导入档案”只执行本地正则、没有调用模型的问题。
- 合并读取玩家勾选的多本世界书后，优先调用 SillyTavern 当前模型生成结构化人物档案。
- 当前宿主未提供模型调用能力时，回退到玩家在催眠手机中配置的 OpenAI 兼容接口。
- 世界书内容按不可信资料处理；提示词明确禁止执行其中的脚本、HTML或指令，原世界书只读且不会被修改。
- 按钮附近新增分析中、成功和失败反馈；提取失败时保留原有档案，不再静默清空。
- 模型可返回女性、男性或未知性别；只自动导入明确分类的人物，未知项会在反馈中提示玩家手动处理。
- 设置页顶部最右侧新增“日志”；记录世界书适配、宿主/自定义模型调用、档案导入以及未捕获运行异常。
- 日志最多保留300条，可复制、下载或清空；API密钥、令牌、密码和敏感请求头字段会脱敏，且不记录世界书正文与模型提示词。

## 自动化结果

- `npm run build`：通过。
- 扩展清单验证：通过。
- Node 单元测试：11/11 通过。
- Playwright 静态预览：桌面端与窄屏均通过。
- 浏览器桥验证：点击档案导入后宿主 `generateRaw` 恰好调用一次，系统提示词包含固定的人物档案结构化合同。
- 返回的测试数据分别导入女性档案与男性档案，并能在原4.3档案界面打开。
- 日志页能显示 `model.host.success` 与 `profile.import.success`，设置顶部标签数为3。
- 手机外层无页面滚动，四边拖动、左右下角同步缩放及其他应用回归保持通过。
