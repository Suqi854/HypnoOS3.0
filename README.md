# 催眠手机 HypnoOS 3.0

独立的 SillyTavern 前端扩展。当前仓库是 `0.6.3 运行兼容修正版`：清理跨应用残留的 MC 能量顶栏，为“本轮输入”增加直接发送，按当前角色绑定关系只读接入世界书与最新楼层/MVU变量，并把插件宿主迁移到独立命名空间以兼容原4.3卡内脚本。核心仍不依赖角色卡脚本、Tavern Helper 或 MVU；进入 RC 前仍需真实宿主逐项验收。

## 当前能力

- 三层数据域：浏览器全局资源、角色资料、聊天状态。
- 中国通用版、日本通用版和完全自定义初值。
- PNG / JSON / CharX / HypnoOS ZIP 角色导入与头像校验、IndexedDB 存储。
- 手机内“本轮输入”应用：自动读取酒馆当前草稿，允许编辑玩家本轮输入，并与批量 APP 操作统一写入输入框（不自动发送）。
- 世界书只读扫描、确定性映射草案、AI 辅助草案、差异预览和 HypnoOS 伴生世界书。
- 默认复用 SillyTavern 当前模型；可选 OpenAI 兼容端点。密钥不会进入扩展设置、导出包、世界书或日志。
- Tavern Helper / MVU 可选同步；缺失时手机核心仍能运行。
- 4.3 桌宠、点按/触屏长按、人物切换、右侧资源栏和手机边框拖动已恢复；桌宠长按菜单的“通用”入口打开独立扩展设置。
- 手机根文档禁止整页滚动，四边透明拖动热区继续工作；帮助、设置、人物档案等应用仍在各自内容区滚动。

## 安装与预览

SillyTavern 最低版本为 `1.18.0`。将发布 ZIP 解压到 `public/scripts/extensions/third-party/HypnoOS3.0` 后，在扩展管理中启用。不要把源码仓库中的 `legacy/` 安装进宿主；构建包会自动排除它。

```powershell
npm test
npm run check
npm run build
npm run preview
```

静态预览地址为 `http://127.0.0.1:6633/`。静态预览不等于真实酒馆验收。

## 安全边界

- 角色包、世界书和 AI 输出全部视为不可信数据。
- 导入器不执行卡内脚本、HTML、宏或远程 URL。
- 来源世界书只读；写入操作只针对带 HypnoOS 所有权元数据的伴生世界书。
- 伴生书重扫比较来源哈希和上次生成快照；检测到人工修改或外来条目时阻止覆盖。
- 手机 UI 是许可基线内的本地固定代码，不从网络加载脚本。
